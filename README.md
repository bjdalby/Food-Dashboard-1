# Restaurant Order Analytics Dashboard

## Run locally

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run:
   `pip install -r requirements.txt`
4. Then run:
   `streamlit run app.py`

The app opens in your browser.

## Data
The first version reads the `Actually Cleaned Data` sheet from `Subway Database (1).xlsx`.

Later, the data model can be standardized to include a `Restaurant` column so the same dashboard can compare multiple restaurants.
